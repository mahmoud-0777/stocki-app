# 📦 Stocki

**Stocki** is a dedicated inventory and store management application built specifically for Algerian retail businesses and small merchants.

---

## 🌟 Overview

Stocki simplifies daily store operations for Algerian shop owners by providing fast stock tracking, sales logging, and essential reporting in a clean, local-friendly interface.

### Key Features
* 🇩🇿 **Algerian Market Ready:** Built-in support for DZD (DA) currency and local receipt/invoice formats.
* 📦 **Stock Management:** Real-time inventory tracking, categorization, and low-stock warnings.
* 🧾 **Sales & Receipts:** Quick sales recording with barcode scanner support.
* 📊 **Simple Analytics:** Summary of daily revenue, top-selling items, and profit margins.
